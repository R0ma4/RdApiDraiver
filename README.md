# RdApiDraiver
RdApiDraiver - это универсальный драйвер для общения с устройствами поддерживающими REST API на HTTP и HTTPS

### Начало работы и DSL язык
Для обработчика нет стандартного "расщирения" с которым он работает, движок обрабатывает исключительно содержимое 
документация доступна по _ссылке_

#### установка
 + скачайте драйвер
 + распускайте и запустите его
 + откройте любой текстовый редактор или скачайте EditCode(наш редактор) и создайте шаблон "Работа с API устросва"
 + напишите код-клиент (если вы не создавали шаблон с помощью EditCode)
 > http://localhost:5412/api/[devaisename]
  или используйте _http://localhost:5412/api/test/_ и, если всё хорошо и вы сделали всё правильно GET должен вернуть "Hellol, Users!" 

 ### Поддержка
 Прямых библиотек для работы с данным драйвером официально -нет
 но вы можете использовать готовые client-коды в папке основного дрвайвера
